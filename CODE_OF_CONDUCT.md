# Código de Conduta

Esperamos uma colaboração profissional, respeitosa e tecnicamente honesta.

São bem-vindos debates, revisões e discordâncias construtivas. Não são aceitos assédio, discriminação, intimidação, exposição de dados pessoais, ameaças ou uso dos canais do projeto para promover atividades não autorizadas.

Relatos de conduta inadequada devem ser feitos de forma privada por um canal oficial divulgado no perfil [@00infosec](https://x.com/00infosec). A equipe poderá moderar, editar ou remover contribuições e restringir a participação quando necessário para proteger a comunidade.
